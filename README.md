# Palomino's Oversized Wheels & Tires Website

Static responsive website ready for GitHub and Vercel.

## Deploy
1. Upload the full folder contents to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Other / Static.
4. No build command is required.

## Before final launch
- Confirm business hours with owner and add them to Contact section.
- Connect a real quote form endpoint (Formspree, Web3Forms, CRM, etc.). Current demo opens the visitor's email client.
- Connect owner's preferred booking/calendar system once supplied.
- Confirm financing provider/details before adding specific financing claims.
- Replace or reorder gallery photos as desired.
